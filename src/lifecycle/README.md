# Lifecycle guidance

Four Codex command hooks provide model-aware guidance without rewriting tool output or agent parameters. `guidance.mjs` owns the subagent/tool contracts, `index.mjs` dispatches Git/project prompt guidance and preloads project commands and deduplicates tool advice, `advice.mjs` reads the turn router's credential-bound snapshot, and `install.mjs` manages this package's hook definitions and specialist profiles.

UserPromptSubmit detects Git and project operation intent before the first tool and prefers existing suitable specialists. It reads local manifests for CLI keywords and commands, including on general development prompts. SubagentStart announces the actual model and requests evidence in the final handoff. PostToolUse offers delegation guidance once per turn plus one structured-failure reminder. SubagentStop requests a summary only for an empty final message and never continues twice. These hooks cannot switch an active agent's model; the parent must select a supported model when creating a permitted child task.

Hooks make no network/model calls. Advice expires after five minutes and health weighting expires with its source data. No prompt, transcript contents, commands, results or credentials are persisted. Installation preserves other hooks, uses content-addressed scripts to require fresh trust after code changes, and never edits Codex's trust store.

Complex parent prompts receive planner/executor candidates and a bounded implementation packet contract. Child prompts do not recursively receive parent planning instructions. SubagentStart distinguishes actual models from candidates; PostToolUse reminds the parent to assess each decomposed task separately. An execution role with a conflicting fixed model is excluded rather than silently overriding the economical candidate.
