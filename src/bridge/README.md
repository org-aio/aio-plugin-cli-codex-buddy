# App Server 标准输入输出代理

新轮次先尝试 `dispatch` 的确定性工具分发。符合本地权限和完整短句条件的请求映射为原生 `thread/shellCommand`，使用原生 turn ID、输出、退出码和持久化记录，并跳过供应商。其余请求进入模型选择，改写 `turn/start.model` / `effort` 及桌面 collaborationMode。

工具审批、请求 ID、服务器反向请求和未知消息透传；活动轮次 steering 不改模型。通过原生 `warning` 显示实际路径，规则直达标注模型为无，模型选择在服务器接受后显示已启用。失败不自动重放。

状态文件只保存规则/模型、等级、原因、时间、退出码及任务/轮次 ID，不保存原提示词、完整命令输出或凭据。`dispatch` 模块负责规则、权限门槛和原生生命周期，bridge 保持协议编排职责。
