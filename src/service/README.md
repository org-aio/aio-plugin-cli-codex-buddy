# 后台同步

将单文件 CLI 复制到 Codex 目录，避免依赖 npx 临时缓存。macOS 使用 LaunchAgent，Linux 使用 systemd 用户 timer，Windows 使用当前用户的计划任务。任务只保存运行路径，不保存凭据。watch 命令提供不依赖系统调度器的前台模式。

卸载分为调度器清理与配置恢复：调度器缺失或报错不阻断恢复，只撤销仍指向本工具的配置项；保留备份、鉴权和其他设置。缺失主状态时使用独立的初始配置备份。卸载等待正在写入的同步退出后回滚，保留旧运行时的路径保护标志，并用 uninstalled 禁止新版重新启用；只有 setup 可以解除。调度器清理失败保留元数据以便重试。
