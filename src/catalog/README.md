# 模型目录

标准模型列表决定成员顺序，同一供应商 Codex 清单独有的 ID 追加在末尾；旧目录、内置目录、隐藏模型或网关元数据均不补充这两类实时响应之外的 ID。元数据优先级为当前客户端内置模型、已有自定义模型、可选网关清单、保守通用默认值。不靠模型名称推断推理、视觉或工具调用能力。

输入能力：网关的视觉助手能为任何被路由的模型把图片转成描述，因此每个目录条目统一声明 `text` + `image`，不因上游清单只写 `text` 而关闭客户端图片输入；`supports_image_detail_original` 仍只跟随上游显式声明。其他字段仍遵守上述优先级，客户端需要重新加载目录后才能使用更新后的能力。
